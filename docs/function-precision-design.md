# 函数级精度：基于渐近分析的设计

> 日期 2026-10-10。状态：设计稿，未实现。
> 调研基础：`research_notes/asymptotic-precision-zk-functions-20261010-1252/report.md`

## 1. 问题

值层面的精度是 `|w − v| < 1/k`（k 为公开参数）。
函数层面需要对应的精度概念：当 witness 是一个函数（多项式系数）
而不是一个值时，"逼近得有多好"由什么度量？

答案：**渐近阶数 d**。`R = O(x^d)` 是一个精确可验证的陈述——
残差的前 d 个系数为零，即 d 个线性约束，0 乘法门。

## 2. 双轨精度模型

| 轨道 | 参数 | 含义 | 在哪验证 |
|---|---|---|---|
| 点精度（渐近阶） | d | 残差 `R = O(φ_d)`，即前 d 个广义系数消失 | 电路内，线性约束 |
| 区间精度（极小极大） | E | `‖f − p‖∞ ≤ E` 在区间 [a,b] 上 | 公开参数，离线 Remez 算好 |

- d 类比 k：越大越精确，都是公开参数。
- E 由 Chebyshev 等振荡定理保证：n+2 个交错点即有限证书。
- 现有 sin/cos/exp/ln 的 Chebyshev 逼近就是 E 轨道的实例。

## 3. 渐近尺度声明

`R = O(φ_N) ⟺ 前 N 个广义系数为零` 对一切尺度成立，
但变成有限电路约束只在残差能用规范函数有限表示时：

| 尺度 | 适用 | 电路处理 |
|---|---|---|
| `{x^n}`（x→0） | Taylor 型 | d 个线性约束（当前实现） |
| `{x^{−n}}`（x→∞） | Stirling、erfc | 同上（变量代换后） |
| `{e^{−nx}}`、`{x^n e^{−x}}` | 边界层、WKB、Airy 前因子 | 先提非多项式因子 `R=e^{−x}S(x)`，再约束 S 的系数 |
| `{(ln x)^m/x^n}` | li(x) 等 | 同上 |

**设计规则**：陈述必须声明尺度。精度参数 d = 消失的广义系数个数。

## 4. 语法草图

```
ode(y' = y + O(x^5), y(0) = 1)
```

- `O(x^5)`：残差的渐近阶（公开精度参数，类比 k）。
- 系统自动生成约束：`(i+1)c_{i+1} − c_i = 0`（i=0..4）+ `c_0 = 1`。
- witness：系数 `(c_0..c_5)`（私密）。
- canonical：`ode(y'=y+O(x^5),y(0)=1)`（符号形式，不含数值）。

## 5. 铁律

1. **只证明系数/逼近多项式，不证明"THE 函数"**。
   Stokes 现象：`f` 与 `f + e^{−1/x²}` 共享渐近展开，
   电路无法区分。陈述的是逼近多项式，诚实注记写清楚。
2. **扇区声明**：含 `e^{−x}` 等尺度时，声明并范围检查扇区
  （如 `|arg z| ≤ π − δ`），Stokes 线两侧展开形式不同。
3. **点阶数 ≠ 区间精度**：某点的渐近阶 d 不能推出区间误差。
   要区间保证，走 E 轨道（Chebyshev）。
4. **Poincaré 语义**：电路证明的是代数事实"x^d 整除 R"，
   不执行任何极限；"x→0" 在有限域上无意义。
5. **DLMF 可用**：Ai(z)、erfc、Bessel 的渐近展开与余项界
   （dlmf.nist.gov）可直接作为公开残差数据。

## 6. 做不了的（诚实边界）

- 奇异摄动/匹配渐近：没有有限代数形式（层宽选择、匹配、
  拉伸变量三处 blocker）。
- "THE 函数"唯一性：Watson 定理要无穷多界，电路里拿不到。
- Taylor 余项显式界进电路：理论上可行（多项式不等式+范围检查），
  但全网无先例，是开放问题。

## 7. 与现有工作的关系

- FTC 积分：d=1 的特例（`F' = f` 即 `F' − f = O(x^0)` 的退化）。
- Chebyshev 超越函数：E 轨道的实例（`‖f − p‖∞ ≤ E`）。
- 本设计统一两者：d 管点，E 管区间。
