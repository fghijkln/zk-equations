# Witness 用户视角：以后可能会看到什么

> 写给不懂密码学的普通用户。描述设计全部实现后，App 里可能的样子。
> 日期 2026-10-10。

## 主界面

打开 App，最上面是一个输入框，写你要证明的方程。下面有几个按钮。

### 现在就有的

**方程输入框**
你在这里打字，比如 `x^3+2*x+5=38`。以后还能写 `x^2+1=0`（答案是虚数 i）、
`x = int(x^2, 0, 1)`（积分）、`ode(y' = y, y(0) = 1)`（微分方程）。

**witness 输入框（"秘密答案"）**
你知道的那个数，填这里。比如方程是 `x^3+2*x+5=38`，你填 `3`。
这个数不会出现在证明里，别人拿到证明也反推不出来。

**精度 k 输入框**
必填。你要求答案精确到什么程度：k=1000 就是误差小于千分之一。
k 越大，证明越慢，自己权衡。

**"求解"按钮**
不知道答案？点它。App 会算出方程的解（包括虚数解比如 `i`、`1+2i`），
点一下解就自动填进 witness 框。积分方程点它会显示积分值。

**"生成证明"按钮**
点它，App 用你的秘密答案生成一份证明。证明是一串看不懂的字符，
可以复制、保存、发给别人。**证明里没有你的秘密答案**，只有方程本身。

**"验证证明"按钮**
收到别人的证明？把方程、证明、k 填好，点它。App 告诉你这证明是真是假。
注意：验证时 k 要你自己填，不能信证明里带的（那是防作弊的）。

### 以后可能有的（积分和微分方程上线后）

**方程输入框的新写法**

- 写 `x = int(x^2, 0, 1)`：意思是"我知道 x² 从 0 到 1 的积分值"。
  点"求解"会显示 `0.333333333333`，点进 witness 框就能生成证明。
  证明里只写 `x=int(x^2,0,1)`，**不会出现 0.333… 这个数**。

- 写 `ode(y' = y, y(0) = 1, deg = 5)`：意思是"我知道一个 5 次多项式，
  它在 5 阶精度下满足 y'=y 且 y(0)=1"（这是 e^x 的 5 次 Taylor 逼近）。
  witness 会是一组系数（App 自动算好填进去，你不用手算）。

**"查看逼近说明"按钮（可能叫"诚实注记"）**
积分/微分方程的证明，App 会附一句话告诉你这证明到底在说什么，
比如："本证明的对象是 5 次 Taylor 多项式，不是 e^x 本人。"
这是为了不骗你——多项式毕竟不是真正的 e^x。

**精度的新含义**
以前 k 是"答案差多少"，以后对方程里的函数，会多一个"阶数"概念：
`deg = 5` 就是 5 阶精度，阶数越高逼近越好（证明也越大）。
k 照样填，两个都要。

## 别人拿到你的证明能看到什么

- 能看到：方程本身（`x=int(x^2,0,1)`）、k、证明字符串。
- **看不到**：你的秘密答案、积分值、多项式系数。
- 想知道答案？自己算去——方程是公开的，App 不拦着。
  但"从证明里反推"这条路是堵死的。

## 一句话总结

你负责想方程、找答案；App 负责把"我知道答案"这件事变成一份
别人验得出真假、但看不到答案的证明。积分和微分方程只是把
"答案"从一个数升级成了一个函数，按钮的用法没变。
