# Witness v0.4.3 设计：复系数方程与复根

> 状态：设计稿（2026-10-10），待评审。基于 2026-10-10 的论文调研
> （`research_notes/complex-numbers-zk-circuits-20261010-1113/report.md`）。

## 1. 目标

支持复系数方程与复数 witness（根）。示例：

```
方程：(1+2i)*x^2 + 3*x = 1-i
witness：x = i
```

证明"我知道复数 w 使 P(w) = 0"，witness 的实部虚部都不泄露。

## 2. 语法

复数字面量（大小写不敏感的 `i`）：

| 写法 | 含义 |
|---|---|
| `i` | 0+1i |
| `-i` | 0-1i |
| `3i` / `-2i` | 0+3i / 0-2i |
| `1+2i` / `1-2i` | 1+2i / 1-2i |
| `2*i` | 0+2i（乘法形式也接受） |
| `1.5+0.5i` | 1.5+0.5i（小数亦可） |

规则：
- 虚部必须以 `i` 结尾；`1+2i` 中间允许空格（`1 + 2i`）。
- 为避免歧义，`i` 不做变量名（现有语言只有变量 `x`，无冲突）。
- 方程写法与现有完全一致，只是系数可以是复数：
  `(1+2i)*x^2 + 3*x = 1-i`。

## 3. 内部表示

- `Complex = (re: Fraction, im: Fraction)` —— 一对精确有理数。
- 多项式：`{exp: Complex}`，指数到复系数的字典。
- witness：`Complex`，实部虚部各最多 12 位小数（与现有精度一致）。

## 4. 解析器改动

扩展现有 tokenizer/parser：
- 识别 `i` 后缀，把 `a+bi` / `a-bi` / `bi` / `i` 解析为 `(Fraction(a), Fraction(b))`。
- `parse_polynomial` 返回复系数多项式（实数方程是虚部为 0 的特例）。
- 保持现有实数语法 100% 兼容。

## 5. 电路编译

### 5.1 复数编码

`a+bi ↔ (a, b)` 一对域元素，`i` 纯形式化（调研结论：全行业标准做法；
`i` 不需要在域里存在）。

### 5.2 复乘法（schoolbook，4 门）

`(a+bi)(c+di) = (ac-bd) + (ad+bc)i`，4 个乘法门：
`t1=a*c, t2=b*d, t3=a*d, t4=b*c; re=t1-t2, im=t3+t4`。

取舍说明：Karatsuba 3 门法（El Housni ACNS'23）在配对电路里是标准优化，
但 schoolbook 更易审计；Python 原型先用 schoolbook，Rust 重写时再评估
3 门法。（调研：无独立 benchmark 证明 3 门在通用 DSL 里更快。）

复平方可用 2 门（`(a+b)(a-b) + 2abi`），实现时对平方单独优化。

### 5.3 多项式求值

沿用现有幂链结构，每个"乘法"换成复乘法（4 门）：
- 常系数 × 复数：线性组合，**免费**（系数公开）。
- 复数加法：分量相加，**免费**。
- 只有 witness 相关的非线性乘法（x²、x·y 等）耗门。

例：`(1+2i)x²+3x=1-i`，witness `x=i` —— 只需 **2 个门**（一次复平方）。

### 5.4 exact 模式（高斯整数）

条件：所有系数实部虚部皆为整数，且无超越函数/小数字面量。
- 电路：证 `re(P(w)) = 0` 且 `im(P(w)) = 0`（mod N 精确成立）。
- witness 必须为高斯整数（实部虚部皆整数），否则友好报错
  （提示改写方程如 `x^2 = 2.0` 走 tolerance）。
- k 仍必填（预检用），canonical 恒含 `;k=<k>`。

### 5.5 tolerance 模式

条件：其余一切（小数系数、超越函数、非高斯整数）。
- 定点：`W = (round(re·10⁴), round(im·10⁴))`；系数 `C_e = round(S·c_e / M^e)`，
  `S=10⁷⁰, M=10⁴`（与实数版同；M 的幂次在乘法中恰好抵消，见 §5.3 推导）。
- 设 `R = re(P_scaled(W))`，`I = im(P_scaled(W))`（整数）。
- 电路证：`R² + I² ≤ B²`，其中 `B = ceil(S/k)-1`。
  （2 个平方门 + 一次 bit 分解 range check；Bulletproofs 原生支持 range proof。）
- 含义：`|P(w)| < 1/k`（复模）。

### 5.6 精度定义（预检，honest prover）

沿用 0.4.2 定义，把模换成复模：
```
min_r |w - r| < 1/k      （|·| 为复模，r 取遍复数根）
```
k 为用户必填（0.4.2 既定规则，不变）。

## 6. 求解器

Aberth–Ehrlich 本就是为复数设计的（**三阶收敛**，MPSolve 在用）；
我们的 `solve.py` 已是它，需：
1. 支持复系数多项式求值（`p(z)/p'(z)` 复数运算，Python `complex` 即可）。
2. 复数初始猜测点（n 个互异，如单位圆上 scaled roots of unity）。
3. 返回 `"a+bi"` 字符串（各最多 12 位小数）。
4. round 到定点后、证明前重验残差（防舍入）。

## 7. API

- `prove_equation(eq, witness, k)`：witness 接受 `"1+2i"` 字符串
  （亦接受 `(re, im)` 元组）；k 必填（不变）。
- `verify_equation(eq, proof, k)`：签名不变；k 必填且绝不从 proof 读（不变）。
- `solve_equation(eq)`：返回 `["1+2i", ...]`（复数字符串）。
- `proof["equation"]`：canonical 复方程，如 `"(1+2i)*x^2+3*x-1+i=0;k=1000"`；
  witness 对永不进明文（沿用积分讨论的输出红线）。

## 8. UI

- 方程输入框：接受 `i` 记法（现有输入框直接兼容）。
- witness 输入框：接受 `"a+bi"` 格式。
- "查看方程的解"：显示复根，点击填入 witness 框。
- 精度 k：沿用必填框（不变）。

## 9. 安全与诚实声明

1. **零因子**：secp256k1 标量域 `n ≡ 1 mod 4`，故 `Fp[x]/(x²+1)` 不是域
   （有零因子）。影响：加减乘电路不受影响；我们的电路不用复除法；
   诚实值远小于 √n，不可能触及零因子。文档中诚实注明。
2. **tolerance 是放宽**：`R²+I² ≤ B²` 接受近似根，声明强度弱于精确版；
   与实数版 tolerance 性质一致。
3. **未审计**：沿用项目一贯声明。

## 10. 实现步骤

1. 解析器：复数字面量（`core/circuit.py` 的 tokenizer/parser）。
2. 复数 helper：对 `(Fraction, Fraction)` 的加减乘（Python 层）。
3. 电路：复 wire 布局、复乘门（4 门）、复平方（2 门）。
4. exact 模式：高斯整数分支。
5. tolerance 模式：`R²+I² ≤ B²` 的 bit 分解。
6. 求解器：复 Aberth–Ehrlich。
7. API：witness `"a+bi"` 解析。
8. 测试：高斯整数方程、复系数方程、复根、精度边界。
9. UI：输入/显示格式。

## 11. 非目标

- 复除法/复超越函数（sin/cos 的复数版）—— v0.4.3 不做。
- Karatsuba 3 门乘法 —— 留给 Rust 重写时评估。
- 极坐标/其他编码 —— 电路不友好，不做。
